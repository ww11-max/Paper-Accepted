## 它是什么

Paper Accepted 不是通用润色工具。

它先理解**目标期刊的结构、论证顺序与写作惯例**，诊断你的稿件与成稿样貌之间的差距；再与你确认一份改写蓝图，最后逐章改写、校验、交付。

你的研究事实、数据与结论不被改写；被改写的是结构、论证的组织方式，以及不符合期刊惯例的表达。

> 适用：准备投稿英文期刊的中文稿或英文稿；结构松散、章节比例失衡、表达偏离期刊惯例；希望在保留研究事实的前提下提升规范度与可读性。
>
> 不适用：代写、补数据、编造文献；承诺录用；完全离线使用。

---

## 核心能力

| 能力 | 说明 |
|---|---|
| **期刊结构对齐** | 按目标期刊的章节结构、论证顺序与篇幅比例诊断稿件，指出需要重组、合并、前置或后移的章节。 |
| **对话式改写蓝图** | 先给出结构现状与改写建议，与你确认后再动笔。不擅自重组你的论证，也不跳过你的判断。 |
| **逐章改写** | 以原文为事实来源逐章改写，不以编造数据或文献的方式“补全”内容；不确定处显式标出。 |
| **交付前校验** | 数字、术语、引用与前后一致性检查；不达标会标出并回退或重写，而不是静默交付。 |
| **成稿导出** | 导出 Word 成稿与逐章对照稿；支持期刊论文与学位论文两类稿件。 |
| **经验库** | 只采纳你确认过的偏好与纠正；越用越贴合你的写作习惯。经验只保存在你的电脑上。 |

## 工作流程

1. **上传稿件** — 支持 `.docx`、`.md`、`.txt`，单文件不超过 10 MB。
2. **结构诊断** — 识别章节、论证链、篇幅比例与目标期刊的差距。
3. **确认蓝图** — 用对话的方式确认哪些章需要重组、哪些是改写重点、风格倾向如何。
4. **逐章改写** — 按确认后的蓝图逐章处理；每章可暂停、回看、按章重做。
5. **校验与导出** — 交付前做一致性与规范性校验，导出 Word 成稿或对照稿。

整个过程不会跳过你的确认直接改完整篇；每一步都可以停下来讨论。

## 支持期刊

已内置以下期刊的结构模板、写作规范与语料参照：

| 期刊 | 简称 |
|---|---|
| Applied Economics | AE |
| China Economic Review | CER |
| Economic Analysis and Policy | EAP |
| Emerging Markets Review | EMR |

每个期刊使用独立的章节结构、写作规范与成稿样貌；后续会持续增加。

## 适合谁

- 准备投稿经济学、金融学、管理学期刊的研究者
- 需要把中文稿改写为英文投稿稿的作者
- 需要按学校或学科规范整理结构、表达与章节比例的学位论文作者
- 希望保留研究事实，只提升结构、论证与表达的写作者

## 不适合谁

- 需要代写、补数据或编造文献
- 希望系统保证论文被录用
- 需要完全离线使用

## 下载与开始

1. 打开 [Releases](https://github.com/ww11-max/Paper-Accepted/releases/latest) 下载最新 Windows 包。
2. 解压整包到任意目录（例如 `D:\PaperAccepted`），**不要只把 exe 拖出来**。
3. 双击 `Paper Accepted.exe`。
4. 输入激活码（`PA-XXXX-XXXX-XXXX`，由发放渠道提供）。
5. 首次使用建议先上传一份样稿，完整走一遍结构诊断与蓝图确认。

**运行环境**：Windows 10 / 11（64 位）；使用期间需要保持网络畅通。

## 常见问题

**会改变我的数据和结论吗？**

改写以原文为事实来源。数字、术语与引用不做无依据替换；交付前会校验并标出偏差。结构重组会先征得你的确认。

**能保证录用吗？**

不能。Paper Accepted 做的是让稿件达到目标期刊的结构与写作规范，降低形式性退稿风险；录用取决于研究本身与同行评审。

**支持哪些文件格式？**

`.docx`、`.md`、`.txt`，单文件不超过 10 MB。

**中文稿可以用吗？**

可以。中文稿会先做学术翻译，再按目标期刊改写；翻译与改写分阶段进行。

**换电脑怎么办？**

本机数据不会自动跟随。请在旧设备上导出备份，在新设备导入；激活码换机请联系发放渠道。

**断网能用吗？**

不能。结构诊断、改写与校验都需要联网完成。

**支持学位论文吗？**

支持。学位论文会按学科与学校规范处理章节结构、篇幅比例与表达；与期刊投稿稿使用不同的结构路径。
